## Portfolio Task 1

### Assessment Details
* **Launch date:** 17th June 2026
* **Submission deadline:** 16th July 2026
* **Module outcomes assessed:** 1, 2, 3, 4, 5
* **Assessment weighting:** 70%
* **Word count:** 2000 words (+/- 10%)

### Task Description
Students are required to design, build, evaluate, and demonstrate a complete machine learning system that solves a real-world problem. This task is assessed through a single technical report that documents the full development process from start to finish and the working system deployed on Streamlit community cloud. All instructions on how to do this will be taught in the class. 

Your report must provide a clear, step-by-step account of how the system was developed, including the reasoning behind every key decision. The work should show strong engineering practice and experimental rigour: how the problem was framed, how data was handled, how models were implemented and debugged, how performance was evaluated and compared, and how the final approach was selected based on evidence.

The report must include visuals throughout (e.g., workflow diagrams, plots, tables) and must also include screenshots of relevant code and outputs to demonstrate implementation progress and technical work carried out. 

The aim is for a reader to understand exactly what you did, why you did it, and what you learned from the results.

#### Marking Breakdown
* **Problem Definition and System Framing (15%):** Clear definition of the real-world problem, justification for using machine learning, and formulation of the task.
* **Data Pipeline and Feature Handling (25%):** Description and justification of data preparation steps, transformations, and feature handling.
* **Model Implementation and Debugging (30%):** Implementation of model(s), evidence of debugging and iterative improvement, and explanation of key design choices.
* **Experimental Evaluation and Model Selection (20%):** Rigorous evaluation, comparison of models using appropriate metrics, and justification of the final model selection based on results.
* **Presentation, Structure, and Communication (10%):** Clarity, organisation, quality of visuals and screenshots, and overall professionalism of the report.

*Note: Make sure to include your ipynb file of the project in the GitHub repository.*

### Submission Instructions
Submit a single Word or PDF document online via the Turnitin link in Moodle.

Your submission must be one consolidated report and must include:
* A clear step-by-step development narrative (from problem definition to final results)
* URL to your streamlit deployed application
* Screenshots of key code sections used (not full code dumps) and screenshots of important outputs
* Visual evidence of evaluation (e.g., charts, confusion matrices where relevant, error plots, metric tables, cross-validation results)
* Diagrams or figures where appropriate (e.g., pipeline diagram, model comparison summary, system overview)

### Hints and Tips
* Attend the scheduled workshops on report writing and critical analysis.
* Refer to academic journals, case studies, and textbooks provided in the module reading list.
* Use the lecture notes and recommended resources to deepen your understanding of machine learning concepts.

## Portfolio Task 2

### Assessment Details
* **Launch date:** 27th June 2026
* **Submission deadline:** 29th July 2026
* **Module outcomes assessed:** 1, 5
* **Assessment weighting:** 30%
* **Word count:** 1000 words (+/- 10%)

### Task Description
Students must produce a Model Card for the final machine learning system, following the structure and style of the provided example model card (Gemini-3-Pro). The Model Card should act as a professional disclosure document that communicates the model’s purpose, context, performance, limitations, and responsible use.

#### Required Sections and Weighting
1. **Model Overview and Intended Use (20%)**
   * High-level description of the model and the real-world problem it addresses.
   * Clear explanation of intended users, deployment context, and appropriate use cases.
   * Explicit statement of non-intended or inappropriate uses.
2. **System and Data Summary (10%)**
   * Concise description of the model type, inputs, and outputs.
   * High-level summary of the data used and any important assumptions.
   * *No implementation or algorithmic detail is expected.*
3. **Evaluation and Performance Summary (30%)**
   * Clear summary of how model performance was evaluated.
   * Presentation of key results in an accessible, non-technical way.
   * Brief acknowledgement of evaluation limitations or uncertainties.
4. **Limitations, Risks, and Responsible Use (30%)**
   * Critical discussion of known limitations, risks, and potential misuse.
   * Consideration of ethical, societal, or deployment-related concerns relevant to the problem domain.
   * Reflection should be grounded in the real-world context, not abstract ethics.
5. **Presentation and Communication Quality (10%)**
   * Clarity, structure, and professionalism of the Model Card.
   * Effective use of headings, tables, and visuals in line with the provided model card template.
   * Appropriate tone for an informed but non-expert audience.

*Note: This task does not require new experiments, code, or model training. Content should summarise and reflect on the system developed in Task 1. The Model Card should read as a standalone professional document, not a technical report. Model cards in the below link can be used as guidance for the task: https://modelcards.withgoogle.com/model-cards*

### Generative Artificial Intelligence (GenAI) Guidance
The use of Generative AI tools to generate, paraphrase, or edit any written content in this assessment is strictly prohibited and will be treated as plagiarism. All written work must be the student’s own original work. Generative AI may be used only for coding and debugging support and must not be used to produce any written explanations, analysis, or report content.
